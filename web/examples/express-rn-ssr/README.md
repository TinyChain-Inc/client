# Express + RN SSR Example

This directory is the canonical example reference for the `client/web` scaffold.

This example is runnable directly from this directory and delegates to the root
`client/web` build/test scripts.

## Run

```bash
# requires Node.js 20.x
cd client/web/examples/express-rn-ssr
npm run bootstrap
npm run dev
```

Then open `http://localhost:3000`.

## Build + Start

```bash
cd client/web/examples/express-rn-ssr
npm run build
npm run start
```

## Testing

```bash
cd client/web/examples/express-rn-ssr
npm run test
npm run test:browser
```

For detailed test-layer guidance, see
[`client/web/TESTING.md`](/home/haydn/Documents/tcv2/client/web/TESTING.md).
